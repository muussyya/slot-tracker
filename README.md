# スロ収支(スロット収支・確率管理 PWA)

ビルド不要の静的ファイルのみで動作します。データは端末のブラウザ内(localStorage)にのみ保存されます。

## スマホで使うまで

PWA(ホーム画面追加・オフライン動作)には **HTTPS で配信** する必要があります。例:

- **GitHub Pages**: このフォルダをリポジトリに push → Settings → Pages で公開
- **Netlify Drop**: https://app.netlify.com/drop にフォルダをドラッグ&ドロップ

公開URLをスマホで開き、
- iPhone(Safari): 共有ボタン → 「ホーム画面に追加」
- Android(Chrome): メニュー → 「ホーム画面に追加」/「アプリをインストール」

> 注意: データは「その端末・そのURL」に紐づきます。URLを変えると別データになります。定期的に「データ」タブからJSONエクスポートしてください。

## PCでの動作確認

```
python -m http.server 8000
```
→ http://localhost:8000 を開く

## ファイル構成

| ファイル | 内容 |
|---|---|
| index.html | 画面構成(記録 / 機種別 / 全体 / グラフ / データ) |
| app.js | 保存・集計・グラフ・インポート/エクスポート |
| style.css | スタイル(ダークモード対応) |
| sw.js | Service Worker(オフライン対応)。更新時は `VERSION` を変更 |
| manifest.webmanifest, icons/ | PWA設定・アイコン |

## 確率計算のルール

- 「総回転数 ÷ 回数」を全実戦の **合計同士** で計算(平均の平均ではない)
- 総回転数と、その項目の回数が両方入力された実戦だけが対象(未入力は除外)
- 合算確率(BB合算・RB合算・ボーナス合算)は、構成する項目がすべて入力された実戦のみ対象。0回のときは空欄ではなく「0」を入力
